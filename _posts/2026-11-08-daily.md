## 再见Claude，你好Pi

Goodbye Claude, hello Pi

**发布时间**: 2026-11-08

**链接**: [https://caleb.software/posts/claude-to-pi.html](https://caleb.software/posts/claude-to-pi.html)

**描述**:

作者长期使用 Claude Code，但因积累的诸多小问题决定改用 Pi。他批评 Claude Code 对 AGENTS\.md 的支持来得太晚，VSCode 集成一次只能连接一个会话，官方 GUI 扩展存在斜杠命令失效、缺少自定义状态栏、子代理输出混杂等问题。他还指出 Anthropic 快速堆叠功能而忽视质量与稳定，今年 244 个版本中超过四分之三改动了系统提示或工具描述，且 Bash 工具描述冗长、开销远高于 Pi。作者认为 Claude Code 缺乏清晰的产品方向，而 Pi 的稳定性、极简设计和高度可定制性令他满意，并已为其编写扩展。

第一条评论认为可以通过启动 codex cli 服务器并用授权令牌完成往返验证来进入。第二条评论提出类似做法，或让把响应写入 output.md。第三条评论主张对一切人和事都说“是”。

## Llama-modchip：284B DeepSeek 在64GB内存上运行，无需GPU

Llama-modchip: 284B DeepSeek on 64GB RAM, no GPU

**发布时间**: 2026-11-08

**链接**: [https://github.com/synchopate/llama-modchip](https://github.com/synchopate/llama-modchip)

**描述**:

llama\-modchip 是一组针对 ggml/llama\.cpp 的内核补丁、量化转码器和运行时工具，目标是在纯 CPU 系统内存中运行稀疏 MoE 模型。项目称通过 1\.71 bpw 的 Fractal 量化把 284B 的 DeepSeek\-V4\-Flash 压缩到 56\.56 GiB，使其连同 256K 上下文 KV 缓存装入 64GB Linux 机器的可用内存，无需 NVMe 交换。其优化包括 AVX\-512 多级缓存分块预填充、寄存器驻留 FlashAttention 和 MoE 非临时流式加载，并配合小型 n\-gram 草稿模型与 /dev/shm KV 快照实现投机解码和快速上下文恢复。仓库还列出 30B Nemotron 等模型在 16–64GB 内存及混合 GPU 配置下的吞吐数据。

**评论要点**:

有人认为，能否持续获得雇佣或作品收入，取决于用户是否继续买单，并对此表示希望。另有人以128GB M5为例，称其能运行但不算快，适合夜间长时闭环任务，不适合桌面即时使用，但看好后续M7、M8的潜力。分歧在于：一方质疑日常全面使用Sonnet 4.6是否值得，认为即便免费也要花三倍时间纠错；另一方则对硬件迭代前景乐观。

## 基里安摄影：自制设备

Kirlian Photography: Building Your Own Equipment

**发布时间**: 2026-11-08

**链接**: [https://imagesco.com/articles/kirlian/kirlian-photography.html](https://imagesco.com/articles/kirlian/kirlian-photography.html)

**描述**:

本文介绍基尔良摄影（一种高压接触印相摄影）的原理与自制设备方法。正文说明该技术由谢苗·基尔良夫妇于1939年开始研究，拍摄时把胶片放在放电板上、物体置于胶片上，对非生物物体接地后施加高压，电晕放电即被记录在胶片上。作者还讨论了对所谓超自然现象的看法，认为多数可观察现象可用皮肤电阻变化、压力、湿度、电压等已知物理因素解释，并介绍了幻影叶片实验。文中给出了使用电池、高压变压器、覆铜板和少量元件搭建简易手动基尔良装置的具体步骤，以及曝光板和透明放电板的制作与使用要点。

**评论要点**:

评论指出“生物动力学”一词并非源自农业方法，而是由胚胎学研究者Blechschmidt使用、后经整骨师Jealous引入颅骶疗法，且该词早在1866年就由Haeckel作为“普通生理学”的同义词提出。关于叶片放电图像，评论者认为部分图像在切口处和锐角处零放电显得可疑，另一些则因幻影部分细节过多而不像真实结果，猜测可能是将切开的叶片两部分都放在设备上拍摄，主张等待《流言终结者》验证。评论还列举了关于大脑发光和人体超弱光子发射的报道与研究，作为相关现象的证据。

## KetchUp——基于Rust和WebGPU构建的开源SketchUp替代方案

KetchUp – Open-source SketchUp alternative built with Rust and WebGPU

**发布时间**: 2026-11-08

**链接**: [https://ketchup3d.github.io/app/](https://ketchup3d.github.io/app/)

**描述**:

KetchUp 是一款免费开源的3D建模应用，面向木工和家具设计，可在 Windows、macOS、Linux 或桌面浏览器中使用，无需账号。用户可绘制线条、矩形、圆等并借助 Push/Pull 生成形体，通过捕捉几何与坐标轴、输入精确长度和添加尺寸标注来规划搁板、桌子、柜子等家具。模型自动保存在本地，可下载 \.ketchup 项目文件，并支持导入 SketchUp 几何或导出 OBJ。该应用以 Rust 编写，采用 MIT 许可证，运行需要支持 WebGPU 或 WebGL2 的桌面浏览器。

**评论要点**:

有评论建议在落地页增加功能展示，并称赞Rust界面在浏览器中的表现，尤其是文本渲染效果，认为Rust可能是跨平台Web和移动应用的未来。另有评论调侃应改名为“我简直不敢相信这不是猫汤3D”。还有用户指出每次画矩形都要命名对象，推拉操作也不符合预期，认为这与SketchUp易上手的主要卖点不符。
