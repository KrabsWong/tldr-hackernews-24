## Pi 1.0

Pi 1.0

**发布时间**: 2026-10-01

**链接**: [https://earendil.com/posts/pi-1-0/](https://earendil.com/posts/pi-1-0/)

**描述**:

Earendil 发布 Pi 1\.0，这是一个经过加固、极简且可扩展的智能体运行框架。新版本新增 Codemode（原生支持 MCP 及 Jev、图像模型等非 LLM 模型）、虚拟模型扩展支持、延迟工具加载、Anthropic 模型缓存预热、对话中途系统消息、新 TUI 主题和默认全屏模式。同时发布的还有实验性包 Pi Durable，用于构建长时间运行的智能体应用，两者均采用 MIT 许可。

**评论要点**:

托尔金若在世，大概会对AI和科技公司滥用《指环王》中那些被黑暗腐蚀的名字感到不满，尤其这些名字本属于堕落或邪恶之物。讨论中也有人提到，Eärendil公司用TypeScript起步只是图方便，未来不排除移植到Rust或汇编。另有用户推荐在Claude Code之外尝试oh-my-pi发行版，认为在多个工具间切换体验尚可。

## iOS版StreetComplete现已进入公开测试阶段

StreetComplete on iOS is now in public beta

**发布时间**: 2026-10-01

**链接**: [https://github.com/streetcomplete/StreetComplete/issues/5421](https://github.com/streetcomplete/StreetComplete/issues/5421)

**描述**:

StreetComplete 的 iOS 移植开发以 GitHub Issue \#5421 作为协调主工单，取代了此前的 \#1892。该应用代码库完全使用 Kotlin 编写，计划通过 Kotlin Multiplatform 和 Compose Multiplatform 实现 iOS 版本，以保持单一代码库、降低后续维护成本。开发步骤包括分离平台相关代码、将 UI 逐步迁移到 Compose Multiplatform；截至 2024 年上半年迁移约完成 50%，估计完整移植需约一人年的工作量，项目欢迎社区贡献和赞助。

**评论要点**:

在高速公路等受控通道上步行通常违法，因此即便没有标识，也应按不可步行处理，这是支持回退编辑者的核心理由。反对者则认为，维基百科内容需要具体、可引用的表述，不能仅因“发生过”或“通常如此”就作笼统断言，例如牛奶是否冷冻销售、面包是否切片，都因地区而异，必须明确范围并附来源。分歧在于：一方强调法律事实应直接反映，另一方强调百科表述必须精确且有据。

Clef: Open-weight decision models, and new RL fine-tuning platform

**发布时间**: 2026-10-01

**链接**: [https://blog.cloudflare.com/clef-decision-models/](https://blog.cloudflare.com/clef-decision-models/)

**描述**:

Cloudflare 发布了两款自研决策模型 Clef 和 Clef\-flash，托管于 Workers AI，并以 Apache 2\.0 许可在 Hugging Face 开源。决策模型可基于概率输出有界结构化结果，用于代理工作流中的分类与路由，Clef 具备视觉编码器和 64k 上下文窗口，且与 Jev API 兼容。Cloudflare 同时推出强化学习微调服务，先由 FDE 团队提供定制化微调，后续将发展为自助平台。

Returning from vacation? The government can search your phone without a warrant

**发布时间**: 2026-10-01

**链接**: [https://arstechnica.com/tech-policy/2026/09/immigration-advocate-sues-border-agents-for-demanding-his-cell-phone/](https://arstechnica.com/tech-policy/2026/09/immigration-advocate-sues-border-agents-for-demanding-his-cell-phone/)

**描述**:

阿根廷裔美国作家兼移民倡导者托马斯·肯尼迪起诉联邦政府，要求删除他本月早些时候重新入境美国时被海关与边境保护局（CBP）人员从其手机中复制的数据。诉状称，迈阿密国际机场的CBP人员搜查了他的行李、盘问其书籍和杂志，并威胁若不交出手机就延长审讯、无限期扣留手机，随后将手机带走约45分钟，他怀疑期间数据被复制，最终未被起诉即获释。肯尼迪认为自己是因在佛罗里达从事移民权利组织和政治活动而被针对，要求政府删除这些敏感数据。联邦法院长期承认第四修正案的“边境例外”，允许无需搜查令搜查人员和电子设备；CBP称此类搜查极为罕见，2025财年在4\.19亿旅客中仅搜查了55318名国际旅客的电子设备。
