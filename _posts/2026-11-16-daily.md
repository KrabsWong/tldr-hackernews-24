## Jiff 1.0：Rust 的日期时间库

Jiff 1.0: A datetime library for Rust

**发布时间**: 2026-11-16

**链接**: [https://burntsushi.net/jiff/](https://burntsushi.net/jiff/)

**描述**:

Jiff 是一个面向 Rust 的日期时间库，1\.0 版本已发布，并被 uv、Cargo、Starship、fd、Nushell 等项目采用。该库将时区处理置于 API 核心，自动处理夏令时等常见问题，并承诺长期保持 1\.0 API 稳定。文章介绍了其核心类型体系，包括 civil::Date、civil::Time、Timestamp、TimeZone 和 ZonedDateTime，以及 Span 与 SignedDuration 两种时长类型，并演示了时区歧义（fold 与 gap）的多种解析策略。

**评论要点**:

日期时间API设计极易出错，夏令时等规则本身带有政治性且会任意变动，金融场景中“加一天”究竟指加24小时还是次日同一时刻，跨夏令时切换时更会引发实际争议。有评论指出Arrow缺少独立的日期和时间类型，推荐“一切用datetime”在许多场景下是对数据的糟糕表示并导致意外行为，而Chrono的问题严重程度不及此；该评论同时澄清若指Apache Parquet接口库则另当别论。另有评论调侃Jiff发音说明是刻意制造争议的营销手法，自己正是为此点开链接，并更倾向于“gif”用硬g的读法。
