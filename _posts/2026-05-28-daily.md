## 厌倦与AI对话

I'm Tired of Talking to AI

**发布时间**: 2026-05-27

**链接**: [https://orchidfiles.com/im-tired-of-ai-generated-answers/](https://orchidfiles.com/im-tired-of-ai-generated-answers/)

**描述**:

作者对AI生成回答感到厌倦。他发现GitHub仓库传播恶意软件，向AI求助无果后发起讨论，却收到与AI相同的回复。工作中，同事用ChatGPT截图回答业务问题，内容错误且不相关。在Reddit上，他发现与其对话的竟是AI代理。即使与真人交流，对方也转用AI回答。作者渴望与真实人类沟通，但日益泛滥的AI回复令人失望。

**评论要点**:

评论核心观点：审查AI生成的计划比审查原始代码更高效。当变更范围较小且假设正确时，AI能够生成准确的方案，但新手常犯的错误是放任AI自由发挥，导致其做出错误假设，因此必须提前干预。此外，懒散的工程师可能直接要求抛弃原有代码，完全依赖AI重新生成。评论者还表达了对同事直接转发AI答案的不满：自己本就拥有AI且能获得更好结果，提问是为了得到人类针对性的解答，而非已掌握的AI回复。

## 人类全部烹饪压缩至2兆字节

All of human cooking compressed into 2 megabytes

**发布时间**: 2026-05-27

**链接**: [https://arxiv.org/abs/2605.22391](https://arxiv.org/abs/2605.22391)

**描述**:

该论文提出了Epicure，一个基于跳字模型的食材嵌入家族，在多语言食谱语料库上重新训练。作者收集了414万条食谱，涵盖11个来源、7种语言（英语、中文、俄语、越南语、西班牙语、土耳其语、印尼语、德语和印度英语），并通过LLM增强管道将原始食材字符串规范化为1790个规范条目。进一步构建了包含203,508条边的食材-食材NPMI图和80,019条边的带类型FlavorDB食材-化合物图（2,247个带类型化合物节点，15类），以此训练三种Metapath2Vec变体：Cooc（仅游走共现图）、Chem（仅游走化合物元路径）、Core（混合两者），三者共享架构和超参数，仅在随机游走模式上不同，从而在化学与食谱上下文的谱系上占据不同位置。

**评论要点**:

该评论的核心观点是：烹饪模型应基于生物分类学（taxon）对食材进行精确分类，而非仅依赖通用名称。以“squash”（南瓜/西葫芦）为例，不同品种（如Jarrahdale南瓜和直颈南瓜）在烹饪中效果差异巨大。作者建议将食材作为分类单元的一部分，建立通用名称与分类单元的“多对多”映射，并抽象出如“南瓜籽”这种跨分类的复合定义。对于模糊的食材名称（如“squash”或“pumpkin seed”），模型应主动要求用户根据其所在地进行澄清，因为同一名称在不同地区可能指代不同物种。这样才能确保食谱的准确性和实用性。

Go: Support for Generic Methods

**发布时间**: 2026-05-27

**描述**:

该提案建议为Go语言添加泛型方法（generic methods）。当前Go规范不允许方法拥有自己的类型参数，只能通过泛型接收者间接使用类型参数。这是因为传统上方法被视为实现接口的手段，而泛型接口方法难以高效实现。但提案认为，具体方法（concrete methods）本身就有独立价值——它们用于组织代码和提供链式调用的语法优势，不一定非要实现接口。因此，建议修改语法，允许方法声明像函数一样拥有自己的类型参数。修改后的语法为：`func Receiver MethodName [TypeParameters] Signature [FunctionBody]`。这样，泛型具体方法不会参与接口实现（因为接口方法不能有类型参数），但能独立使用，满足用户长期以来的需求。

**描述**:

这是一个名为 xlide_vscode 的开源项目，允许用户在 VS Code 中直接编辑 Excel VBA 代码。它提供侧边栏树状视图浏览模块、语法高亮、符号导航（转到定义、查找全部引用、重命名符号）等功能，并通过 Ctrl+S 将更改保存回 .xlsm 文件。该项目无需 COM 自动化或 Office 安装，支持 Windows、macOS、Linux 和远程容器。其架构基于 Python 后端（使用 pyOpenVBA 和 openpyxl），通过 JSON-RPC 2.0 协议与 VS Code 扩展通信，支持虚拟文件系统（xlide-vba://）和 LiveShare 协作，并可向 GitHub Copilot 暴露所有操作。关键设计包括长驻 Python 进程、通过 FileSystemProvider 实现读写、无 Office 依赖的纯二进制读取，以及为 AI 代理设置写入确认以防止误操作。
