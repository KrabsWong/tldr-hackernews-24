## Claude Code隐写标记请求

Claude Code is steganographically marking requests

**发布时间**: 2026-06-30

**链接**: [https://thereallo.dev/blog/claude-code-prompt-steganography](https://thereallo.dev/blog/claude-code-prompt-steganography)

**描述**:

文章作者在审查 Claude Code 客户端时发现其系统提示中嵌入了隐写术标记。通过改变日期字符串中的撇号（如 `'` 改为 `\u2019`）和日期分隔符（`-` 改为 `/`），Claude Code 能在用户不易察觉的情况下，将请求来源信息编码进提示文本。触发条件为 `ANTHROPIC_BASE_URL` 环境变量或特定时区（如 Asia/Shanghai）。域名和 AI 实验室关键词列表经过 base64 和 XOR 编码，用于识别 API 网关、代理或模型蒸馏管道。作者认为，虽然这一功能可能用于检测未经授权的 API 使用，但隐蔽实现方式损害了用户信任，尤其影响了那些进行正当自定义路由的开发者。对于使用官方端点的用户，该路径不会激活。作者呼吁开发工具应明确说明行为，而非隐藏信号。

**评论要点**:

评论核心围绕AI安全议题的争议展开：一方认为AI安全领域类似宗教，缺乏实证基础；另一方反驳其具有理性推理，并指出对方回避关键问题。评论还对比了中美政治体制，质疑为何一个压制批评、审查媒体的国家应先于民主国家实现超级智能。整体讨论聚焦于AI安全的可信度与地缘政治伦理的矛盾。

## 克劳德十四行诗5

Claude Sonnet 5

**发布时间**: 2026-06-30

**链接**: [https://www.anthropic.com/news/claude-sonnet-5](https://www.anthropic.com/news/claude-sonnet-5)

**描述**:

Anthropic 发布 Claude Sonnet 5，这是迄今最具代理能力的 Sonnet 模型，能自主规划、使用浏览器和终端等工具运行。其性能接近更高阶的 Opus 4.8，但价格更低；相比前代 Sonnet 4.6，在推理、工具使用、编码和知识工作方面显著提升。安全评估显示不良行为率更低，且网络安全能力远低于当前 Opus 模型。即日起在所有计划中可用（免费/专业版默认模型，Max、团队、企业版均可使用），也支持 Claude Code 和 API。推出优惠定价：每百万输入 token 2 美元、输出 10 美元（至 2026 年 8 月 31 日），之后分别为 3 美元和 15 美元。早期合作伙伴反馈一致：Sonnet 5 能完成此前模型会中途停止的复杂任务，主动检查输出，并以低成本完成代理工作。

**评论要点**:

用户尝试用Sonnet替代Opus作为项目子代理以加速HPC内核实验，但Sonnet未写出任何代码，只是空转浪费Token。实践表明，没有框架会用低能力模型写代码，成本权衡不值得；低能力模型更适合读代码。常见思路“大模型写计划、小模型写代码”容易出错：小模型遇到计划未覆盖的细节时，要么猜测导致计划崩坏，要么传回大模型处理，而大模型读代码成本远高于写代码。因此，写代码仍需使用前沿模型，如Amp虽使用多个提供商，但仍用前沿模型写代码。

## 欧洲数字ID钱包依赖谷歌和苹果的安全服务

**发布时间**: 2026-06-30

**链接**: [https://waag.org/en/article/european-digital-id-wallets-are-gift-google-and-apple/](https://waag.org/en/article/european-digital-id-wallets-are-gift-google-and-apple/)

**描述**:

欧洲政府正在推出数字身份钱包，但其安全性依赖于谷歌和苹果的远程认证服务（如谷歌Play Integrity API和苹果Managed Device Attestation）。这导致公共基础设施被私有公司控制：谷歌的API不仅检查设备完整性，还强制要求使用谷歌许可的安卓系统、通过Play商店安装应用并登录谷歌账户，可能违反《数字市场法案》。荷兰和意大利的钱包已采用该服务，排除了使用去谷歌化系统（如e/OS、GrapheneOS）的用户。欧盟虽声称打破科技垄断，却在此过程中强化了谷歌的生态系统控制。ID钱包作为访问关键公共服务的数字公共基础设施，必须保持跨设备和系统的互操作性，避免供应商锁定。文章指出，存在更开放的替代方案（安卓硬件认证API），但被忽视。最终，用户若想使用身份钱包，被迫接受谷歌软件，这与欧洲倡导的开放、包容和技术主权相矛盾。

**评论要点**:

评论核心观点：一是推荐支持EDRI组织以获取有利的游说力量；二是介绍Heads工具通过TPM硬件密钥验证启动完整性，无需专有固件且用户可完全控制；三是强调利用欧盟身份证的智能卡功能，数字签名与加密完全在卡片芯片内完成，无需第三方认证，类似现有EMV支付和登录系统。

## 美国劳动收入份额降至战后最低

The labor share of income in the US is at its lowest post-war level

**发布时间**: 2026-06-30

**链接**: [https://libertystreeteconomics.newyorkfed.org/2026/06/the-post-covid-decline-in-the-labor-share/](https://libertystreeteconomics.newyorkfed.org/2026/06/the-post-covid-decline-in-the-labor-share/)

**描述**:

根据纽约联邦储备银行的研究，美国劳动力收入份额在疫情后降至二战以来的最低水平。该指标衡量经济产出中用于支付工人工资的比例，其下降意味着生产率或价格上涨快于工资增长。分析显示，疫情后的劳动力份额下降模式与2000年前的经济衰退期相似：衰退期间劳动力份额上升，随后在复苏期下降并趋于平稳。这与2000年后（如全球金融危机期间）的持续下降模式不同。研究指出，尽管劳动力份额在2000年代后显著下降，但疫情后的下降在周期性和行业重新分配效应上与传统衰退期一致，可能是周期性而非结构性因素驱动。目前劳动力份额比疫情前低1.6个百分点，处于历史低位。

**评论要点**:

1. 评论者认为，创业需要远超25万美元的资金，而普通家庭更愿意用这笔钱给孩子买房，而非冒险投入互联网初创企业。  
2. 评论者指出，客户和护理人员都面临困境，其开发软件旨在降低管理成本、改善运营，但行业中仍存在因无能或恶意导致的剥削现象。  
3. 评论者主张颠覆房地产行业，降低房价、淘汰现有业主，重新调整激励以聚焦居民生活质量；并强调百分比回报与投资基数无关，长期估值和租金增长才需改变。
