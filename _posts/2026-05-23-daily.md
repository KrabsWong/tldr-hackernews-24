## 为何日本公司涉足如此多不同领域

Why Japanese companies do so many different things

**发布时间**: 2026-05-22

**链接**: [https://davidoks.blog/p/why-japanese-companies-do-so-many](https://davidoks.blog/p/why-japanese-companies-do-so-many)

**描述**:

日本企业普遍存在高度多元化经营的现象。以Toto为例，这家全球最大的马桶制造商，其核心业务是卫浴陶瓷，但自1988年起，旗下“先进陶瓷部门”开始生产半导体制造中不可或缺的静电卡盘（e-chuck）。随着AI需求爆发式增长，高带宽内存芯片需求激增，带动了静电卡盘的需求。如今，这一原本不起眼的部门已成为Toto最大的利润来源，股价大涨60%。Toto并非孤例，许多日本公司如京瓷等，都横跨多个看似不相关的领域。这种独特的多元化战略，源于日本企业对技术积累的长期投入和对新兴机会的敏锐把握。

**评论要点**:

第一段：失败企业的资本回报率通常较低，数据支持这一观点，但这并不意味着这些公司的“目的”就是提供低回报。第二段：讽刺进步派人士因有人主张政府应更高效、少花钱多办事而激烈反对。第三段（日本用户观点）：日本的“准时制生产系统”实质上是剥削分包商。与服务器资源不同，实体工厂难以灵活调整规模，导致员工工资被压低。大企业有工会，但分包商没有；保护分包商的法律在实践中无效，因为起诉大企业会失去业务。日本经济建立在牺牲他人之上。

## AI对现有技术技能的倍增效应

AI has a multiplying effect on existing technical skills

**发布时间**: 2026-05-22

**链接**: [https://www.joshwcomeau.com/email/wham-launch-005-elephant-2-p/](https://www.joshwcomeau.com/email/wham-launch-005-elephant-2-p/)

**描述**:

这篇文章讨论了AI对编程职业的影响。作者承认AI在编程任务上表现出色，但认为人们错误地认为人类开发者将不再被需要。实际上，AI的成功案例大多来自像Matt Perry这样有深厚专业知识的开发者，他们利用AI大幅提升效率。而缺乏经验的人在使用AI时往往陷入困境，难以突破MVP阶段。作者强调，AI是一种工具，需要熟练技能才能发挥其作用，就像乐器或运动装备一样。人们容易高估工具本身的价值，而低估了专业知识和经验的重要性。AI更像钢铁侠的战衣，需要人来操作。因此，学习编程技能依然重要，尤其在结合AI使用时更有价值。

**评论要点**:

该评论围绕两个核心观点展开：首先，AI（如Claude）能生成高质量的代码，但需通过简单规则（如模块拆分、测试覆盖、注释精简）和precommit hook约束，避免代码变成不可维护的“slop”；关键在于人类最终负责大方向重构，这样就能获得良好代码并轻松维护。其次，关于一项AI对学习影响的研究，评论者指出其方法与摘要矛盾、样本量小且期刊可疑，但引用了包含80多项研究的元分析，并提供了来自斯坦福、Anthropic等机构的附加研究，认为虽然研究质量参差，但结论一致，不能轻易否定。

**描述**:

Cleve Moler是MathWorks公司的联合创始人，也是MATLAB编程语言的最初作者。他曾在斯坦福大学、新墨西哥大学等高校担任教授，在数值分析和矩阵计算领域做出重要贡献。1984年，他与Jack Little共同创立MathWorks，将MATLAB商业化并推向市场。如今，MATLAB已成为全球工程与科学计算领域的标准工具，广泛应用于学术研究、工业设计和教育。本文回顾了Moler的学术生涯、MATLAB的诞生历程及其对计算技术发展的深远影响。

评论主要围绕对 Cleve Moler 和 MathWorks 公司的敬意与怀念。第一条评论回顾十年前在公司工作的经历，称赞其运营良好、私有且员工分享成功，肯定了 Jack Little 的领导。第二条评论表达对未看到“黑条”纪念的失望，并称赞 Moler 是伟人。第三条评论详细回忆 1990 年代在 Matlab 课程中偶遇 Cleve Moler，受其论文启发出版矩阵包，并强调 Cleve 对数值计算前端代码的追求深刻影响了作者后来的 Python 贡献（如高精度数学函数）。评论一致认为 Cleve Moler 的遗产永存，是行业标杆。

## 受Forth启发的网站编写语言

A Forth-inspired language for writing websites

**发布时间**: 2026-05-22

**链接**: [https://robida.net/entries/2026/05/21/a-forth-inspired-language-for-writing-websites](https://robida.net/entries/2026/05/21/a-forth-inspired-language-for-writing-websites)

**描述**:

作者受Forth启发，设计了一种基于栈的网站编写语言Forge。其核心语法通过堆栈操作生成HTML，例如定义`h1`词输出标题标签。Forge可轻松嵌入微格式，如`dt-published`和`p-author`。网站结构包含库文件`lib.forge`、样式表和`pages`文件夹。单个二进制文件运行站点，内置WebAssembly编译器：服务端编译.forge文件生成HTML供爬虫和WebMentions使用，客户端则通过service worker在导航时抓取源文件并实时编译，实现SPA体验。语言限制下，数据可持久化到状态、localStorage或服务器追加日志（JSONL格式）。例如点赞按钮通过`log-append`向日志追加数据。表单提交到.forge页面，数据入栈后由目标处理。作者认为该语言奇特而有趣，可能用于个人网站。

**评论要点**:

评论核心观点：第一，Forth类语言极其简洁高效，无需LLM，可从原语快速自举，解释器与编译器为同一REPL循环，是一种独特的编程范式。第二，React并非唯一合理方案，其基于JS语义的“属性更新”导致泄漏抽象，使用Hooks处理业务逻辑尤其不当；作者拥有25年GUI经验（含12年React），认为MVC、PAC、自包含组件等替代方案各有优势，React在很多场景下并非最佳选择。

## 象棋不变量

Chess invariants

**发布时间**: 2026-05-22

**描述**:

该文章探讨了如何用形式化方法分析国际象棋中的恒常不变量（invariants）。作者将国际象棋视为一种交替执行的并发系统，通过定义状态和转换，提炼出两类不变量：**状态不变量**（如棋盘上每方恰有一个王、回合奇偶性等）和**转换不变量**（如步数严格递增、回合交替等）。这些不变量帮助捕捉系统的安全性质，确保每一步都符合规则，同时也揭示了棋局中的深层逻辑约束。

**评论要点**:

该评论的核心观点涉及多个层面：首先，评论者指出游戏是基于完全信息的棋类游戏（国际象棋）；其次，提出了一种“同时行动”的并行国际象棋构想——双方秘密写下本回合的移动，然后按规则处理碰撞、通过、逃脱等复杂情况，认为这能增加趣味性；最后，评论者以批判性口吻指出，讨论中的提议要么是0.01%的可能性开创全新范式，要么是99.9%的可能性本可用简单的条件判断和循环在几小时内解决，暗示后者更可能。

## Models.dev：AI模型规格、价格与能力的开源数据库

Models.dev: open-source database of AI model specs, pricing, and capabilities

**发布时间**: 2026-05-22

**链接**: [https://github.com/anomalyco/models.dev](https://github.com/anomalyco/models.dev)

**描述**:

Models.dev 是一个开源数据库，收录 AI 模型的规格、定价与能力。用户可通过 API（`https://models.dev/api.json`）获取数据，并按模型 ID 查询；提供者 Logo 可通过 SVG 链接获取。数据以 TOML 文件组织，存放在 GitHub 仓库中，支持社区贡献。贡献方式包括：若提供者不存在，需创建 `providers/` 下的文件夹和 `provider.toml`（含名称、npm 包名、环境变量等），可选添加 SVG Logo；模型定义放在 `models/` 目录，TOML 文件包含名称、是否支持附件/推理/工具调用/结构化输出/温度控制、知识截止日期、发布时间、开放权重等字段，以及成本、限制、模态等配置。支持通过 `extends` 复用已有模型。该项目也用于内部工具 opencode。

**评论要点**:

评论核心观点：当前模型成本数据缺失关键信息，如模型被削弱的时间、提供商是否频繁路由到更廉价的模型（自适应推理变体）。仅凭每token成本无法反映实际开销，因为模型可能在任务中途变笨导致重试，使真实成本远高于表面数字。建议应持续对模型运行各类任务以评估输出质量，尽管提供商可能通过固定最佳模型来操纵结果。同时，当前列表由OpenCode开发者维护且会及时更新，但缺乏一个涵盖所有可用AI模型的综合数据库，呼吁启动社区贡献项目来填补这一空白。
