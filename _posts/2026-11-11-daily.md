My AI agents found an unmapped Maya site

**发布时间**: 2026-11-11

**描述**:

作者借助多个AI代理分析NASA公开的激光雷达（lidar）数据，在墨西哥丛林中发现一处未列入官方名录的玛雅遗址，从产生想法到收到墨西哥国家人类学与历史研究所（INAH）回复用时不到72小时。代理将约1200平方公里丛林的lidar条带转为图像，逐一筛查金字塔、平台和广场等结构，并核查文献与档案后生成报告提交INAH，对方确认其记录中无该地点。作者推测这是一处古典期（约公元250至900年）的玛雅小型礼仪中心，含广场、至少8至12米高的椭圆形金字塔、抬高庭院和可能的水库。文章更新说明该遗址其实已被考古学家在2025年的一篇论文中测绘过，代理查阅文献时遗漏，因此属于重新发现而非首次发现。

## 蒂姆·彼得斯去世了

Tim Peters has died

**发布时间**: 2026-11-11

**链接**: [https://discuss.python.org/t/in-memoriam-tim-peters-1952-2026/110028](https://discuss.python.org/t/in-memoriam-tim-peters-1952-2026/110028)

**描述**:

Python 社区成员撰文悼念 Tim Peters（1952–2026）。他早年曾任职于 Cray Research 和 Dragon Systems，在 Python 诞生初期成为 Guido 之后最早的用户之一，并深度参与早期 Python 的设计演进，长期担任核心开发者和代码把关者，还创作了《Python 之禅》。他于 2001 至 2014 年担任 Python 软件基金会理事，其幽默、谦逊而严谨的风格影响了众多 Python 项目与开发者。

**评论要点**:

评论区分了“复杂”与“繁琐”两个概念：前者是问题本身固有的、不可避免的难度，后者是人为选择带来的额外负担。有观点认为，应接受UTF-8这类必要复杂度，避免让实现者支持Shift JIS、UTF-16等额外编码，否则整体会变得更繁琐。另一条评论则强调，复杂问题涉及太多未知和相互关联的因素，无法靠规则和流程解决，而繁琐问题可以用规则和流程处理；分歧在于管理者面对问题时往往默认采用繁琐式思维，而非有意识地应对真正的复杂性。

## AWS模拟器

AWS emulator

**发布时间**: 2026-11-11

**链接**: [https://github.com/aws/aws-emulator](https://github.com/aws/aws-emulator)

**描述**:

AWS Emulator 是 AWS API 的本地模拟器，可在本机、开发服务器或 CI 中测试软件而无需调用 AWS 或拥有 AWS 账户，请求发往模拟器并使用模拟资源。它提供无图形界面的本地端点，通过环境变量将 AWS CLI 或 SDK 指向该端点，也支持在 Rust 测试中以嵌入式模式进程内运行。该项目仅用于构建和测试，不适用于生产负载或安全测试，并默认收集使用遥测数据，可通过命令行选项、环境变量、配置文件或嵌入式 API 关闭。

**评论要点**:

现有IAM引擎和balsa语言自成体系，以库形式提供且附带严格免责声明，STS、KMS、服务主体等组件间存在大量不透明交互，难以合理开源或暴露；Cedar曾尝试公开实现下一代IAM语言，但转向授权产品后未真正渗透AWS IAM。分歧在于：一方认为可只替代少数常用AWS服务来开展业务，不必覆盖全部服务和版本，足以获取并留住客户；另一方则对开源或暴露IAM核心机制持怀疑态度。
