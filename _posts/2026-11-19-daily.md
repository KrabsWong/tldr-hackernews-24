**描述**:

Onlook 是一款面向设计师的开源本地优先编辑器，让设计师在真实代码库上进行可视化设计与编辑。它可打开本地任意 Git 仓库并运行用户自己的开发服务器，将运行中的应用显示在无限画布上，支持并排查看移动端、平板和桌面框架。工具不自带模型，而是接入用户已有的 Claude Code 或 ChatGPT/Codex 账户来修改真实文件，并可将成果导出为 HTML、PNG、JPEG 或 PDF。项目采用 Apache 2\.0 许可，目前提供 macOS 桌面版，Windows 和 Linux 版尚未发布。
